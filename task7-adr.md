# ADR-001: Стратегии шардирования для MongoDB в «Мобильный мир»

**Статус:** Принято  
**Дата:** 2025-07-29  
**Участники:** Архитектурный комитет «Мобильный мир»

---

### Коллекция products
- **Атрибуты:**
 - `_id` — уникальный идентификатор товара;
 - `name` — наименование;
 - `category` — категория товара;
 - `price` — цена;
 - `stock` — остаток товара в каждой геозоне (например, `{ "Екатеринбург": 50, "Калининград": 30 }`);
 - `attributes` — дополнительные атрибуты (цвет, размер).

- **Потенциальный шард-ключ:** `category`.
- **Стратегия шардирования:** разделение данных по категориям товаров.
- **Обоснование:**
 - частые операции поиска товаров по категориям требуют эффективного распределения данных по шардам;
 - разделение по категориям позволит равномерно распределить нагрузку, так как запросы будут направлены на соответствующие шарды;
 - упрощает выполнение запросов по фильтрации товаров по категориям и диапазону цен.
 - **Схема коллекции:**
```json
{
  "_id": "unique_product_id",
  "name": "product_name",
  "category": "product_category",
  "price": 0.0,
  "stock": {
    "Екатеринбург": 50,
    "Калининград": 30
  },
  "attributes": {
    "color": "color_value",
    "size": "size_value"
  }
}
```

### Коллекция orders
- **Атрибуты:**
 - `_id` — уникальный идентификатор заказа;
 - `customer_id` — идентификатор клиента;
 - `order_datetime` — дата и время оформления заказа;
 - `items` — список заказанных товаров и их цена (массив документов `{ product_id, price }`);
 - `status` — статус заказа;
 - `total_amount` — общая сумма заказа;
 - `geo_zone` — геозона заказа.

- **Потенциальный шард-ключ:** `geo_zone`.
- **Стратегия шардирования:** разделение данных по геозонам.
- **Обоснование:**
 - операции поиска истории заказов и отображения статуса часто зависят от местоположения клиента;
 - распределение данных по геозонам позволит оптимизировать запросы, связанные с локальными заказами;
 - обеспечивает эффективное распределение нагрузки, так как запросы из разных геозон будут направлены на соответствующие шарды.
 - **Схема коллекции:**
```json
{
  "_id": "unique_order_id",
  "customer_id": "customer_id_value",
  "order_datetime": "ISO8601_datetime",
  "items": [
    {
      "product_id": "product_id_value",
      "price": 0.0
    }
  ],
  "status": "order_status",
  "total_amount": 0.0,
  "geo_zone": "geo_zone_value"
}
```

### Коллекция carts
- **Атрибуты:**
 - `_id` — уникальный идентификатор корзины;
 - `user_id` — идентификатор пользователя;
 - `session_id` — идентификатор сессии (для гостей);
 - `items` — список товаров (массив документов `{ product_id, quantity }`);
 - `status` — статус корзины (`"active"`, `"ordered"`, `"abandoned"`);
 - `created_at` — дата и время создания;
 - `updated_at` — дата и время последнего обновления;
 - `expires_at` — время удаления (TTL) для автоматической очистки старых корзин.

- **Потенциальный шард-ключ:** `user_id`.
- **Стратегия шардирования:** разделение данных по идентификатору пользователя.
- **Обоснование:**
 - основные операции с корзинами (создание, обновление, удаление товаров) связаны с конкретным пользователем или гостем;
 - разделение по `user_id` позволит эффективно обрабатывать запросы для каждого пользователя, минимизируя время отклика;
 - упрощает реализацию операций слияния гостевой корзины в пользовательскую.
 - **Схема коллекции:**
```json
{
  "_id": "unique_cart_id",
  "user_id": "user_id_value",
  "session_id": "session_id_value",
  "items": [
    {
      "product_id": "product_id_value",
      "quantity": 0
    }
  ],
  "status": "cart_status",
  "created_at": "ISO8601_datetime",
  "updated_at": "ISO8601_datetime",
  "expires_at": "ISO8601_datetime"
}
```

## Команды для настройки шардирования

### Создание шардированной коллекции products:
```bash
sh.enableSharding("databaseName");
sh.shardCollection("databaseName.products", { category: "hashed", geo_zone: 1 });
```

### Создание шардированной коллекции orders:
```bash
sh.shardCollection("databaseName.orders", { geo_zone: 1, created_at: 1 });
```

### Создание шардированной коллекции carts:
```bash
sh.shardCollection("databaseName.carts", { user_id: "hashed", status: 1 });
```
